# Contributing

Thank you for helping make VirtualProg better!

VirtualProg's source code isn't public, so this repository doesn't take pull requests. You
contribute here by:

- **Reporting bugs** with the [bug report form](https://github.com/last-Programmer/VirtualProg/issues/new?template=bug_report.yml):
  a clear report with steps to reproduce is the most valuable contribution there is.
- **Suggesting features** with the [feature request form](https://github.com/last-Programmer/VirtualProg/issues/new?template=feature_request.yml),
  describing the problem you want to solve.
- **Voting and adding detail**: a 👍 on an existing issue, or a comment with your setup when you
  see the same problem, helps us decide what to work on first.
- **Confirming fixes**: when an issue says it's fixed in a new version, tell us whether it works for you.

Before opening an issue, please read [Before you open an issue](README.md#before-you-open-an-issue),
and follow the [Code of Conduct](CODE_OF_CONDUCT.md).
