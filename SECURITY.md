# Security policy

Please **don't report security vulnerabilities in public issues**.

Email **support@makeprog.com** with **"Security"** in the subject. Include:

- the VirtualProg version and build (VirtualProg → About VirtualProg) and your macOS version;
- what an attacker could do, and what they'd need (local access, network access, a malicious guest…);
- the steps to reproduce it, or a proof of concept.

We'll confirm we received your report, keep you updated while we work on a fix, and credit you in
the changelog if you'd like. Please give us a reasonable time to ship the fix before disclosing
the issue publicly.

## In scope

- The VirtualProg Mac app, including its HTTP API, web dashboard, `vpvm` command-line tool and MCP server
- VirtualProg Guest Tools for macOS, Linux and Windows
- The VirtualProg apps for iPhone, iPad and Android

Vulnerabilities in macOS, Apple's Virtualization framework or a guest operating system should be
reported to their vendors.
